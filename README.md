📊Project Title:  Google Search Trend Analysis

📌 Project Overview
This project analyzes Google search trends using Python to understand popular search interests across regions and time periods.
The analysis helps identify trending topics and user search behavior using data visualization and data analysis techniques.

🎯 Objectives
- Collect Google search trend data using the Pytrends library
- Analyze search popularity over time
- Identify top regions with highest interest
- Visualize trends using charts and graphs
- Extract insights from search data

🛠️ Technologies Used
- Python
- Pandas
- Matplotlib 
- Pytrends (Google Trends API)
- Jupyter Notebook

💡 Key Learning
- Data cleaning
- Data visualization
- API usage
- Trend analysis
